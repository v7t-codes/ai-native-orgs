## Best pieces

- 🟢 **[How to Build an Agent](https://ampcode.com/how-to-build-an-agent)** — Thorsten Ball, 2025-04
  A working code-editing agent in Go in under 400 lines, with three tools (read_file, list_files, edit_file). The point is that an agent is an LLM, a loop and enough tokens, and the rest is elbow grease.

- **[How I work with Agents](https://x.com/thorstenball/status/2114386050638336082)** — Thorsten Ball, 2026-10
  Working rules: give agents tools to run, deploy, read logs and manage releases and feature flags, test whether AGENTS.md and skills change behavior with controlled experiments, and put "this is not evidence" in AGENTS.md to push for end-to-end proof. Ball personally reviews only the fewer than five central files, such as database migrations.
